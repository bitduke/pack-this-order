# 《这单怎么装？》 (Pack This Order) 🍱

> 极简治愈系外卖装盒益智小游戏，支持 **微信小游戏** 与 **H5 Web 浏览器** 双端运行。

---

## 🎮 游戏介绍

《这单怎么装？》是一款轻松解压的外卖餐盒拼图收纳小游戏。玩家作为外卖打包员，需要将汉堡、薯条、洋葱圈、冰饮、三明治、热汤和蘸酱合理装入餐盒中。

### 🌟 核心特色
- **8 大主线闯关模式**：
  1. 基础摆放：积木式虚线卡槽引导，初学者秒上手。
  2. 冷热分开：热汉堡 ♨️ 与冰饮 ❄️ 必须保持距离。
  3. 专属杯位：冰饮 🥤 必须放置在圆形专用杯位。
  4. 旋转装盒：长条餐品横竖旋转切换，绕开固定隔板。
  5. 成套出餐：薯条与蘸酱 🥫 必须相邻贴边。
  6. 隔板套餐：复杂隔板下的空间解谜。
  7. 一格余量：高难度留白考验。
  8. 双拼满盒：多餐品极限装盒。
- **5 位常客自选模式**：小林、阿岚、阿远、唐姐、周叔特殊偏好点单。
- **双交互模式**：
  - **拖拽直放**：手指按住餐品自由拖拽入盒，松手即装。
  - **点选秒放**：点选餐品再点餐盒目标格，自动吸附对齐。
- **超轻量纯原生渲染**：
  - 基于原生 Canvas 2D 打造，零外部庞大引擎依赖。
  - 整体包体仅 **~280 KB**，秒级冷启动。

## 🛠️ 本地运行与调试

### 1. Web 浏览器运行
无需任何构建步骤，直接启动本地静态 HTTP 服务器：
```bash
# 在项目根目录下
npx serve dist -p 8899
# 或使用 Python
python -m http.server 8899 --directory dist
```
浏览器打开 `http://127.0.0.1:8899` 即可体验。

### 2. 微信小游戏运行
1. 打开 **微信开发者工具**。
2. 选择 **导入项目**。
3. 目录选择 `pack-this-order/wx-minigame`。
4. 填写你的小游戏 AppID（或使用测试号）。
5. 点击进入即可在模拟器中调试与真机预览。

### 3. 代码同步
修改根目录的 `game.js` 后，执行同步脚本即可自动将更改同步至微信小游戏和 Web 产物：
```bash
node sync-wx.js
```

### 4. 自动化测试
```bash
node test-comprehensive.js
```
